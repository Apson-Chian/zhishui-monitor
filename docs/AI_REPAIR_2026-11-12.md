# AI 识别修复 · 2026-11-12

线上版本：`/opt/zhishui-ai/releases/20261112-vision-reliability-v54`。

## 故障与处理

现有智谱密钥可以正常调用。旧主模型 `glm-4.6v-flash` 反复返回 HTTP 429 / 1305，原 `dots3-note-prev` 备用视觉调用还出现超时。旧服务只在 HTTP 429/503 时切换，无法处理格式错误；主备单次均可等待 35 秒，与前端 45 秒总等待时间不一致。用户浏览器实际显示“本次结果未能完整生成”。

比较现有账户可调用的免费视觉模型后，改用 `glm-4.1v-thinking-flash` 为主、`glm-4v-flash` 为备用。无需新账户或新密钥。GLM-4V-Flash 在复杂秦淮例图上曾返回缺少冒号的 JSON，所以保留为备用而非首选。没有修补缺失内容或伪造观察结果。

新服务移除完整的思考/answer/代码围栏包装，再严格校验 JSON 和字段；截断结果、空观察结果或格式错误会尝试备用路由。只有确认为非水域的有效判断直接结束，不再询问另一个模型。故障路由冷却 60 秒；主备共享 30 秒预算，并保留前端 45 秒取消保护。失败只退还对应请求的额度，不重置全站或其他用户额度。
